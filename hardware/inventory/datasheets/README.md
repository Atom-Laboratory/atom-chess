# Datasheets

Store manufacturer datasheets here only after the manufacturer and exact model
or part number are reliably matched to an inventory item.

Recommended path:

```text
hardware/inventory/datasheets/<component-id>/<original-filename>.pdf
```

Then set the component's `datasheet` field to that repository-relative path and
add the matching label photograph or other identification evidence. Do not use a
family-level or visually similar product datasheet as proof of component ratings.
