# Supplied interlocking-board print files

This directory preserves the supplied G-code inputs for board assembly.
Printer, material and machine settings are embedded in those files.
They are hardware reference inputs.

The current MuJoCo board geometry is an explicitly experimental scene model.
A measured assembly and metric calibration are still required before matching
the physical board to robot coordinates.

See [ArUco installation](../../../docs/camera-rl/aruco-installation-guide.md)
and the [simulation examples](../../../simulation/mujoco/README.md).
