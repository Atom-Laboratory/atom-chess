# Hardware evidence

Evidence supports inventory and assembly claims but does not replace engineering
review. Preserve original files where practical; do not edit a photograph to
hide labels or context.

```text
components/<component-id>/  labels, dimensions, measurement records
assembly/                   installed-location and connection photographs
```

Use descriptive filenames, for example `2026-11-05-label-front.jpg`. Reference
files from YAML using repository-relative paths. Notes should identify the date,
observer, measurement instrument where applicable, and what claim the evidence
supports. Avoid committing personal information, serial numbers that must remain
private, credentials, or unrelated background content.
