# S031 — Supervise native local proposals before execution

## Context

M3 defines five local controls and a lease on existing task phases. M2 verified
one native approach/retreat, but not a full grasp workspace. AutonomousControl
already supplies native IK, wrist-aware FK, velocity checking, swept collision
checks and conservative held-object geometry. MotionController and contact/
feedback components supply execution and independent simulation diagnostics.

A watched head-closure attempt reached bilateral contact but timed out because
the generic position-settling rule demanded that fingers penetrate the rigid
piece to reach their requested closing travel. Distinguish intentional compliant
finger closure from arm tracking failure. Arm/wrist tolerances stay unchanged.
Allow a positive finger position error only with bilateral selected-pad contact,
low finger velocity, force-limited actuators and deflection bounded by their
compiled force range divided by position gain. Record the resulting contact
settling mode. This does not relax joint limits or permit other body contacts;
the real camera-only robot cannot assume these simulator force measurements.

The initial full-board stem-grasp screen intersects the D2 pawn. In the same
model with neighbors removed, descent succeeds but stem closure comes within
the 1 mm safety margin between a moving-hand hull and the selected pawn head.
A bounded static screen found a spherical-head-centered candidate clear in
the isolated fixture. Diagnostic trials may explicitly select the existing
stem or head center/radius, retaining the existing aperture/closing-gap
assumptions. This changes target parameters, not collider sizes or permissions,
and is not a learned or hardware-calibrated grasp strategy.

After contact-aware settling, the isolated spherical-head trial grips but loses
bilateral contact while lifting with the old 0.5 mm closing interference. Add
an explicit diagnostic load-factor option: estimate per-finger static normal
load from model mass, gravity and the lower pad/object friction coefficient,
then divide by the smaller finger position gain to propose a closing preload.
The factor is an experimental control margin, not a measured physical dimension.
Keep the old setting as default, reject requests beyond force/joint limits and
retain every existing geometric check. This heuristic must earn its result in
simulation; it is not a grasp guarantee or a hardware force measurement.

Record actuator force traces and allow an explicitly labelled deterministic
lift-speed fraction to distinguish inadequate preload from startup dynamics.
This limits proposals generated by the diagnostic; the supervisor does not
reinterpret policy actions. It does not change controller gains, collider
clearance or physical parameters.

## Decision

Add a simulation-local supervisor that reuses these components with projection
disabled. Bind the declared local bounds/rates to static model limits and the
actual control interval. Validate a whole proposed joint path and the measured
start before issuing a command; recheck the scene/model/reference and ownership.
Capture fresh native RGB perception internally. Reject invalid numeric input,
changed references, stale/replayed frames, IK/velocity/collision failures and
unauthorized phases with structured diagnostics. Never silently scale a proposal.

Immediately before execution, recheck the model, physical/controller identity,
ownership and frame age. Reuse the already validated frame if it is still fresh;
capture another if the sweep outlived its freshness window. This avoids two
full-resolution native vision passes for every tiny action without enlarging
the perception-age bound. Record capture/reuse counts; cached data cannot bypass
state/reference checks, and the runtime stops when its frame expires.

Separate authorization from geometric feasibility. The RL entry point requires
the M3 lease and an actually qualified workspace. It cannot use the current
M2 output to claim training eligibility. A deterministic qualification entry
point may examine/execute individually checked local actions after a verified
M2 approach without retreat. This is an explicitly labelled test lane, bounded
by the same checks, a decision budget and task timeout. It is not an RL lease,
training qualification or a means of asserting grasp/lift success.

For RL execution, also require an on-disk workspace artifact whose SHA-256 is
the declared workspace evidence ID. Bind its model, task/revision, reference,
numeric bounds/rates and simulation-only scope. Referenced baseline reports
must exist, match their recorded hashes and assert successful grasp/lift.
No producer of such a qualified artifact is added here: repeatable baseline
qualification remains M5. Tests use explicitly synthetic success assertions
to exercise this boundary, not as actual manipulation evidence.

Bind qualification sessions to the actual M2 plan/report identities and final
physical/controller state. Reject attempts after intervening simulation changes.
Plans/reports use integrity hashes, not authentication; trusted host code still
owns artifact creation. Reuse model/physical identity checks and existing global
Execution phases rather than duplicating a task state machine.

Keep actuator commands derived from issued-command FK, visual task endpoints
and native IK. Live simulator state is used only for independent safety,
tracking, contacts and result evaluation. Local contact permissions remain the
existing selected-piece pads and resting support; full-gripper hull checks and
other-piece obstacles remain enabled. Record actual geometry and do not trust
historical configuration descriptions of contact profiles.

After partial execution failure, revoke authority and require reconciliation;
hold the issued target at the stop boundary without stepping or teleporting
the model. This is a simulator hold, not a physical emergency-stop guarantee.
No board occupancy is updated and no camera-only grasp/lift assertion is made.

## Alternatives

Directly calling MotionController would omit ownership and complete local path
checks. Reimplementing IK/collision geometry would duplicate existing code.
Reusing autonomous projection would silently change the learned action. Marking
the M2 entry box as a qualified manipulation workspace would bypass M3's gate.
Disabling hulls or neighboring pieces to pass the full-board task changes the
experiment rather than qualifying it.

## Consequences and acceptance

Add adversarial contract/supervisor tests and a documented watched diagnostic
that attempts local descent, closure and lift under these checks. Preserve every
rejection and any partial progress. Distinguish attempted baseline from qualified
grasp/lift; M5 requires repeatable actual manipulation, and M6 remains gated.
No long PPO run or hardware actuation is started by this increment.
